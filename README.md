MindBreak 🧠⚡

MindBreak is a native Android application designed to act as a semi-automatic accountability coach. Instead of relying on easily-dismissed notifications, MindBreak uses Android's SYSTEM_ALERT_WINDOW to drop a transparent overlay directly on top of distracting apps.

To unlock the screen and clear the distraction, users must solve a dynamically generated math or logic puzzle, forcing a "context switch" in the brain to break doom-scrolling habits.

🚀 Features

System-Level Interruption: Uses Full-Screen Intents and Display Over Other Apps permissions to hijack the screen during time-wasting sessions.

Infinite Procedural Engine: Generates randomized algebra equations, percentages, and logic puzzles completely offline so you never get the same question twice.

Custom Goal Tracking: Keep track of what you should be doing right on the main dashboard.

Modern UI: Built entirely with Jetpack Compose using Material Design 3 standards.

🛠️ Built With

Kotlin

Jetpack Compose

Android SYSTEM_ALERT_WINDOW API

StateFlow & Coroutines for background timers

📸 How it Works

Add your productive tasks to the main dashboard.

Toggle "Interruption Mode" ON before you open a distracting app like Instagram or Chrome.

When the timer hits, the app forcefully overlays a puzzle over your current screen.

Solve the puzzle to unlock your phone and return to your productive tasks!
